description: Draft or revise a precise engineering manual chapter with primary citations and tested examples.
---

1. Read AGENTS.md, EDITORIAL.md and closely related published articles.
2. Write a mini-outline of prior knowledge; link published prerequisites and inline-explain any indispensable missing premise.
3. Research original specifications, papers, documentation and reliable textbooks; keep source URLs and mapping to claims.
4. Define every term before first use. Derive complexity, invariants and bounds. Explicitly separate average/worst-case.
5. Include one nontrivial worked example, counterexample, failure modes and verification/exercise.
6. Use a stable lowercase kebab-case ID. Create EN/PT matched Markdown frontmatter and content.
7. For numeric, security, concurrency or correctness-sensitive claims, run tests or clearly label assumptions.
8. Run all validations and report any gaps honestly. Do not publish a placeholder.
