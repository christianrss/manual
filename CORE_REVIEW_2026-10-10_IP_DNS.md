# IPv4 longest-prefix matching and DNS positive TTL cache — technical review (2026-10-10)

Scope: complete bilingual foundation chapter `ip-routing-dns-resolution`, ordered before the end-to-end protocol overview, with an independent oracle for each executable model. No live packet forwarding or resolver implementation is claimed.

**IPv4 route contract:** validate every route tuple, strict/canonical network prefix and IPv4 next hop; match destination using longest prefix, then lower metric, then input order. Unmatched destinations return None. The independent oracle computes numeric bitmask matches rather than calling `IPv4Network.__contains__`. It checks `12 × (1 + 6 + 36 + 216) = 3,108` deterministic prefix-table/destination pairs per language, with duplicate priorities and invalid routes. Real routing protocol preference, live interfaces, ARP/ND, BGP, ICMP and packet MTU are outside the model.

**DNS cache contract:** positive Internet-class A/AAAA address tuples only, ASCII host-label subset, case-insensitive keys, optional terminal dot, monotone integer timestamps, and exact TTL expiration at `now >= inserted_at + TTL`. TTL=0 removes reusable cache entry; independent event oracle computes expiry and reference records without calling the production cache implementation. It enumerates `sum(7**k, k=0..5) = 19,608` histories per language; additional tests reject invalid names, incompatible address families, negative TTL and backward clocks without mutation. No negative caching/NXDOMAIN/NODATA, CNAME traversal, recursive resolution, DNSSEC or RFC 8767 serve-stale.

Primary specifications: [RFC 1812](https://www.rfc-editor.org/info/rfc1812), [RFC 1034](https://www.rfc-editor.org/info/rfc1034), [RFC 1035](https://www.rfc-editor.org/info/rfc1035), [RFC 2308](https://www.rfc-editor.org/info/rfc2308), [RFC 8767](https://www.rfc-editor.org/info/rfc8767), [RFC 8200](https://www.rfc-editor.org/info/rfc8200). Independent tests establish agreement on finite checked domains only, not networking conformance or professional peer review.
