# TCP byte streams and flow control — review (2026-10-10)

The chapter publishes bilingual examples for **application-level framing** and a **relative-offset receiver**. Both are teaching models, not TCP conformance or socket tests. A two-byte big-endian length prefix distinguishes zero-length frames from empty TCP sends. The decoder validates complete headers, applies a configurable size cap, handles split/combined frames and preserves its buffer on rejected oversized chunks. Its deliberately simple copy-on-feed strategy can be quadratic under adversarial one-byte feeds.

The receiver stores out-of-order bytes at offsets within a fixed sliding acceptance interval, returns a cumulative next-expected offset and delivers each byte once. It uses unbounded relative offsets, not 32-bit modular sequence arithmetic, and assumes immediate consumption by the application. First accepted overlapping bytes win **as a teaching-only rule**. It omits retransmission, timers, real advertised-window updates, congestion algorithms, SACK, FIN/SYN, checksums, socket API and network measurements. A helper illustrates additional sender allowance limited by both rwnd and cwnd, not real congestion control.

Independent test evidence: message tuples are used as an oracle across all two-cut frame-stream partitions and single-octet feeds for bounded sets; a **per-position array** reference receiver independently verifies cumulative acknowledgment and pending byte state over exhaustive short event traces with three window sizes in both languages; send allowance is checked against explicit counting of available slots. Invalid values and nonmutation are covered. Passing finite tests does not imply production reliability or formal verification.

References: [RFC 9293 TCP](https://www.rfc-editor.org/info/rfc9293), [RFC 5681 TCP congestion control](https://www.rfc-editor.org/info/rfc5681), [RFC 7323 TCP extensions](https://www.rfc-editor.org/info/rfc7323), and [RFC 4632 CIDR](https://www.rfc-editor.org/info/rfc4632). Remaining: real congestion simulation, modular TCP sequence comparisons and retransmission, flow control under actual application blocking, network capture, TLS cryptography and QUIC.
